# Security Policy

## Supported Versions

The latest release and commits on the `main` branch are actively supported with security fixes and updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Colour Droplet, please do **NOT** open a public issue. Instead, report it privately by sending an email to:

**[kaydenleefale@gmail.com](mailto:kaydenleefale@gmail.com)**

Please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept to reproduce the issue.
- Your OS and Java runtime environment details.

You should receive an acknowledgment within 48 hours. We appreciate your efforts to responsibly disclose vulnerabilities to help keep our software and users safe.
